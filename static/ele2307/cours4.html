Les processus thermodynamiques

Fil conducteur : un processus où l'on fixe une variable (\(p\), \(T\), \(V\) ou \(S\)) ne laisse qu'une seule variable indépendante. Le tableau des dérivées partielles permet alors d'écrire \(dE\), \(dT\), \(dV\) en fonction de grandeurs mesurables (\(C_p\), \(C_V\), \(\beta\), \(\kappa\)). La deuxième moitié du cours traite du transport de la chaleur : loi de Fourier, résistances thermiques et équation de la chaleur.

0. D'où vient ce cours

Le premier principe \(dE = T\,dS - p\,dV + \mu\,dN\) relie cinq variables, mais pour un système fermé non diffusif (\(dN = 0\)) seules deux sont indépendantes. Imposer une contrainte supplémentaire (pression constante, température constante, pas d'échange de chaleur) réduit le problème à une seule variable, et chaque cas simplifié correspond à une situation physique concrète : chauffage à l'air libre, compression lente dans un bain, détente rapide dans un cylindre. Ces processus sont les briques des cycles moteurs du cours 5.

1. Variables, dérivées partielles et tableau 11.1

Deux coefficients mesurables
\[\kappa = -\frac1V\left(\frac{\partial V}{\partial p}\right)_T\ \ (\text{compressibilité isotherme})\qquad\qquad \beta = \frac1V\left(\frac{\partial V}{\partial T}\right)_p\ \ (\text{coefficient d'expansion thermique})\]
\(\kappa \gt 0\) toujours (un corps comprimé se contracte). \(\beta\) est généralement positif ; contre-exemple demandé en classe : l'eau entre 0 et 4 °C se contracte quand on la chauffe (\(\beta \lt 0\)), d'où le maximum de densité à 4 °C et la glace qui flotte.
Tableau des dérivées partielles pour les processus non diffusifs (\(dN = 0\)) - table 11.1 du manuel
\[\left(\frac{\partial S}{\partial T}\right)_p = \frac{C_p}{T}\qquad \left(\frac{\partial S}{\partial V}\right)_T = \frac{\beta}{\kappa}\qquad \left(\frac{\partial T}{\partial V}\right)_S = -\frac{T\beta}{C_V\kappa}\] \[\left(\frac{\partial S}{\partial T}\right)_V = \frac{C_V}{T}\qquad \left(\frac{\partial S}{\partial V}\right)_p = \frac{C_p}{TV\beta}\qquad \left(\frac{\partial T}{\partial V}\right)_p = \frac{1}{V\beta}\] \[\left(\frac{\partial S}{\partial p}\right)_T = -V\beta\qquad \left(\frac{\partial T}{\partial p}\right)_S = \frac{TV\beta}{C_p}\qquad \left(\frac{\partial p}{\partial V}\right)_S = -\frac{C_p}{VC_V\kappa}\] \[\left(\frac{\partial S}{\partial p}\right)_V = \frac{C_V\kappa}{T\beta}\qquad \left(\frac{\partial T}{\partial p}\right)_V = \frac{\kappa}{\beta}\qquad \left(\frac{\partial p}{\partial V}\right)_T = -\frac{1}{V\kappa}\]
\(C_p\) et \(C_V\) sont ici les capacités thermiques du système entier (J/K). Le tableau est fourni au formulaire : il faut savoir le lire, c'est-à-dire choisir la dérivée dont la variable fixée est celle du processus.
Les types de processus
  • Isobare : \(p\) fixée (\(dp = 0\)). Exemple : chauffage à l'air libre.
  • Isotherme : \(T\) fixée (\(dT = 0\)). Exemple : compression lente en contact avec un bain.
  • Isochore : \(V\) fixé (\(dV = 0\)). Exemple : chauffage dans une enceinte rigide ; aucun travail.
  • Adiabatique : pas d'échange de chaleur (\(dQ = 0\), donc \(dS = 0\) si le processus est quasi statique). Exemple : compression rapide, détente dans une turbine.
  • Non diffusif : pas d'échange de molécules (\(dN = 0\)) ; c'est le cas de tous les processus de ce cours.
Valeurs pour un gaz parfait (chap. 12, ex. 28)

De \(V = nRT/p\) : \(\beta = \dfrac1V\left(\dfrac{\partial V}{\partial T}\right)_p = \dfrac{nR}{pV} = \dfrac1T\) et \(\kappa = -\dfrac1V\left(\dfrac{\partial V}{\partial p}\right)_T = \dfrac{nRT}{p^2V} = \dfrac1p\). Ces deux valeurs simplifient toutes les formules ci-dessous.

2. Processus isobare

Pression constante, \(dp = 0\), et en général \(dN = 0\). Du premier principe \(dE = T\,dS - p\,dV\). On exprime tout en fonction de la température :

\[dE = T\left(\frac{\partial S}{\partial T}\right)_p dT - p\left(\frac{\partial V}{\partial T}\right)_p dT\qquad\text{avec}\quad T\left(\frac{\partial S}{\partial T}\right)_p = C_p,\quad \left(\frac{\partial V}{\partial T}\right)_p = \beta V\] \[\boxed{dE = \left(C_p - pV\beta\right)dT}\]
Lecture : la chaleur reçue \(C_p\,dT\) sert à augmenter l'énergie interne et à fournir le travail de dilatation \(p\,dV = pV\beta\,dT\). Gaz parfait (\(\beta = 1/T\)) : \(pV\beta = nR\), donc \(dE = (C_p - nR)dT = C_V\,dT\), \(\Delta W = p\Delta V = nR\Delta T\), \(\Delta Q = nC_p\Delta T\), \(\Delta S = nC_p\ln(T_f/T_i)\).

3. Processus isotherme

Température constante, \(dT = 0\), \(dN = 0\). On exprime \(dE = T\,dS - p\,dV\) en fonction du volume :

\[dE = T\left(\frac{\partial S}{\partial V}\right)_T dV - p\,dV\qquad\text{avec}\quad \left(\frac{\partial S}{\partial V}\right)_T = \frac{\beta}{\kappa}\] \[\boxed{dE = \left(\frac{T\beta}{\kappa} - p\right)dV}\]
Gaz parfait : \(T\beta/\kappa = T\cdot(1/T)\cdot p = p\), donc \(dE = 0\) : l'énergie interne d'un gaz parfait ne dépend que de \(T\) (chap. 12, ex. 13). Toute la chaleur reçue ressort en travail : \(\Delta Q = \Delta W = \int p\,dV = nRT\ln(V_f/V_i)\) et \(\Delta S = nR\ln(V_f/V_i)\).
Question de la diapo 7 : exprimer \(dE\) en fonction de \(dS\)

À \(T\) constante, \(dV = \left(\dfrac{\partial V}{\partial S}\right)_T dS = \dfrac{\kappa}{\beta}dS\) (inverse de \(\beta/\kappa\)), donc \(dE = T\,dS - p\dfrac{\kappa}{\beta}dS = \left(T - \dfrac{p\kappa}{\beta}\right)dS\). Pour un gaz parfait le coefficient vaut \(T - T = 0\), cohérent avec \(dE = 0\).

4. Processus adiabatique

Pas d'échange de chaleur, \(dQ = 0\), donc \(dS = 0\) : l'entropie reste constante (processus isentropique). Les dérivées partielles à \(S\) constante relient \(T\), \(p\) et \(V\) :

\[dT = \left(\frac{\partial T}{\partial p}\right)_S dp,\qquad dT = \left(\frac{\partial T}{\partial V}\right)_S dV,\qquad dV = \left(\frac{\partial V}{\partial p}\right)_S dp\] \[\boxed{\frac{dT}{T} = \frac{V\beta}{C_p}\,dp}\qquad\boxed{\frac{dT}{T} = -\frac{\beta}{\kappa C_V}\,dV}\qquad\boxed{\frac{dV}{V} = -\frac{\kappa C_V}{C_p}\,dp}\]
Conclusions pour un processus adiabatique : une augmentation de \(T\) augmente \(p\) ; une augmentation de \(T\) diminue \(V\) ; une augmentation de \(V\) diminue \(p\). Pour les solides et liquides (coefficients constants), ces relations s'intègrent en \(\ln(T_f/T_i) = (V\beta/C_p)\Delta p\), etc. (chap. 12, ex. 24).
Gaz parfait : \(pV^\gamma = \) constante
\[dE = -p\,dV = \frac{N\nu}{2}k\,dT\quad\text{et}\quad p\,dV + V\,dp = Nk\,dT\quad\Longrightarrow\quad \boxed{pV^\gamma = \text{cste}}\quad\text{où}\quad \gamma = \frac{\nu+2}{\nu} = \frac{C_p}{C_V}\] \[TV^{\gamma-1} = \text{cste}\qquad T\,p^{\frac1\gamma-1} = \text{cste}\qquad \Delta W = -\Delta E = \frac{p_iV_i - p_fV_f}{\gamma-1} = nC_V(T_i - T_f)\]
Démonstration : éliminer \(dT\) entre les deux équations donne \(-p\,dV\cdot\frac{2}{\nu} = p\,dV + V\,dp\), soit \(\frac{dp}{p} = -\frac{\nu+2}{\nu}\frac{dV}{V}\), qui s'intègre en \(pV^\gamma = \) cste. Avec \(pV = NkT\) on obtient les deux autres formes. Une seule mesure de \((p, V)\) permet de prévoir tout le comportement du gaz sans connaître sa température. Air : \(\nu = 5\), \(\gamma = 1{,}4\).
Exemple 3 : convection et inversion thermique dans l'atmosphère

Une parcelle d'air chaud qui monte se détend adiabatiquement (l'air est mauvais conducteur) et se refroidit selon \(T\,p^{1/\gamma - 1} = \) cste. Si elle reste plus chaude (donc moins dense) que l'air ambiant à la même altitude, elle continue de monter : convection. Si l'air au sol est plus froid que ne le prévoit ce refroidissement adiabatique (gradient réel plus faible), la parcelle devient plus froide que son environnement et retombe : inversion thermique, qui piège le smog près du sol. Calcul complet à l'exercice D8.

Processus spécial : la détente libre
\[dE = 0,\ dN = 0,\ \Delta W = 0\quad\Longrightarrow\quad T\,dS = p\,dV\quad\Longrightarrow\quad \Delta T = \left(\frac{p\kappa - T\beta}{\kappa C_V}\right)\Delta V\]
Le gaz se détend dans le vide sans fournir de travail. Avec \(dS = \frac{C_V}{T}dT + \frac{\beta}{\kappa}dV\) (table 11.1) on obtient la formule ci-dessus : une détente libre refroidit un gaz réel (\(T\beta \gt p\kappa\), effet utilisé en réfrigération), mais \(\Delta T = 0\) pour un gaz parfait puisque \(p\kappa = 1 = T\beta\). Processus irréversible : l'entropie augmente (\(\Delta S = nR\ln(V_f/V_i)\) pour un gaz parfait) bien que \(\Delta Q = 0\).

5. Conduction thermique

Le deuxième principe impose que la chaleur s'écoule de la partie chaude vers la partie froide. Pour une plaque d'aire \(A\) et d'épaisseur \(\Delta x\) dont les faces sont aux températures \(T_2 \gt T_1\) :

Loi de Fourier
\[\dot Q = \frac{\Delta Q}{\Delta t} = -kA\frac{\Delta T}{\Delta x}\qquad\qquad j_Q = \frac{\dot Q}{A} = -k\frac{\Delta T}{\Delta x}\ \ (\text{densité surfacique de flux, W/m}^2)\]
\(k\) : conductivité thermique du matériau (W/(m K)) ; \(\dot Q\) est une puissance (W). Le signe moins traduit que le flux descend le gradient de température. En pratique on écrit \(\dot Q = kA(T_{chaud} - T_{froid})/\Delta x\) en valeur absolue.
Résistance thermique et analogie électrique
\[R = \frac{\Delta x}{kA}\qquad\qquad \dot Q = \frac{\Delta T}{R}\quad(\text{comme } I = V/R)\] \[R_{série} = R_1 + R_2 + \cdots\qquad\qquad \frac{1}{R_{parallèle}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots\]
En série (couches traversées successivement par le même flux) les chutes de température s'additionnent ; en parallèle (chemins côte à côte soumis au même \(\Delta T\)) les flux s'additionnent (chap. 12, ex. 47).

6. Équation de la chaleur

La loi de Fourier suffit quand le gradient de température est uniforme (régime permanent). Si la température varie dans le temps, l'énergie s'accumule dans le matériau : ce qui entre moins ce qui sort fait varier l'énergie interne.

\[\frac{dE}{dt} = \dot Q_1 - \dot Q_2 = -\frac{\partial\dot Q}{\partial x}\Delta x = -A\frac{\partial j_Q}{\partial x}\Delta x\qquad\Longrightarrow\qquad \boxed{\frac{\partial\rho_E}{\partial t} = -\frac{\partial j_Q}{\partial x}}\]
\(\rho_E = E/(A\Delta x)\) est la densité d'énergie (J/m³). C'est l'équation de continuité à une dimension : « taux qui entre moins taux qui sort = taux de variation à l'intérieur », valable pour toute quantité conservée.
Équation de la chaleur
\[j_Q = -k\frac{\partial T}{\partial x}\quad\text{et}\quad d\rho_E = \rho_m c\,dT\qquad\Longrightarrow\qquad \frac{\partial\rho_E}{\partial t} = k\frac{\partial^2T}{\partial x^2}\qquad\Longrightarrow\qquad \boxed{\frac{\partial^2T}{\partial x^2} = \frac1K\frac{\partial T}{\partial t}\quad\text{où}\quad K = \frac{k}{\rho_m c}}\]
\(\rho_m\) : masse volumique, \(c\) : chaleur spécifique, \(K\) : diffusivité thermique (m²/s). Un profil de température initialement concentré s'étale comme une gaussienne de largeur \(\sqrt{2Kt}\) : le temps pour qu'une perturbation traverse une épaisseur \(L\) est de l'ordre de \(L^2/K\). En régime permanent (\(\partial T/\partial t = 0\)), \(\partial^2T/\partial x^2 = 0\) : le profil est linéaire et l'on retrouve la loi de Fourier.

7. À retenir

  • \(\beta = \frac1V(\partial V/\partial T)_p\), \(\kappa = -\frac1V(\partial V/\partial p)_T\) ; gaz parfait : \(\beta = 1/T\), \(\kappa = 1/p\). Le tableau 11.1 donne toutes les dérivées partielles utiles.
  • Isobare : \(dE = (C_p - pV\beta)dT\). Isotherme : \(dE = (T\beta/\kappa - p)dV\), nul pour un gaz parfait, \(\Delta Q = \Delta W = nRT\ln(V_f/V_i)\).
  • Adiabatique : \(dS = 0\) ; \(dT/T = (V\beta/C_p)dp = -(\beta/\kappa C_V)dV\) ; gaz parfait \(pV^\gamma = \) cste, \(TV^{\gamma-1} = \) cste, \(\gamma = (\nu+2)/\nu = C_p/C_V\), \(\Delta W = (p_iV_i - p_fV_f)/(\gamma-1)\).
  • Détente libre : \(\Delta E = 0\), refroidit un gaz réel mais pas un gaz parfait.
  • Conduction : \(\dot Q = -kA\,\Delta T/\Delta x\), \(R = \Delta x/(kA)\), \(\dot Q = \Delta T/R\), résistances en série et en parallèle.
  • Équation de la chaleur : \(\partial\rho_E/\partial t = -\partial j_Q/\partial x\) et \(\partial^2T/\partial x^2 = (1/K)\,\partial T/\partial t\), \(K = k/(\rho_m c)\).

Quiz rapide - Cours 4

Une seule bonne réponse par question. Cliquez pour vérifier immédiatement.

Que représente \(\beta = \frac1V\left(\frac{\partial V}{\partial T}\right)_p\) ?

  • La compressibilité isotherme
  • Le coefficient d'expansion thermique
  • La capacité thermique à pression constante
  • Le rapport \(C_p/C_V\)
\(\beta\) mesure la dilatation relative par kelvin à pression constante ; \(\kappa = -\frac1V(\partial V/\partial p)_T\) est la compressibilité isotherme.

Pour un gaz parfait, \(\beta\) et \(\kappa\) valent :

  • \(\beta = T\), \(\kappa = p\)
  • \(\beta = 1/p\), \(\kappa = 1/T\)
  • \(\beta = 1/T\), \(\kappa = 1/p\)
  • \(\beta = \kappa = 1\)
De \(V = nRT/p\) : \(\frac1V(\partial V/\partial T)_p = 1/T\) et \(-\frac1V(\partial V/\partial p)_T = 1/p\).

Un processus isobare est un processus :

  • à pression constante
  • à température constante
  • à volume constant
  • sans échange de chaleur
Isobare : \(dp = 0\) ; isotherme : \(dT = 0\) ; isochore : \(dV = 0\) ; adiabatique : \(dQ = 0\).

Pour un processus isobare non diffusif, \(dE\) s'écrit :

  • \(dE = C_p\,dT\)
  • \(dE = (C_p - pV\beta)\,dT\)
  • \(dE = (T\beta/\kappa - p)\,dV\)
  • \(dE = 0\)
\(dE = T\,dS - p\,dV\) avec \(T(\partial S/\partial T)_p = C_p\) et \((\partial V/\partial T)_p = \beta V\). Le terme \(pV\beta\,dT\) est le travail de dilatation.

Un gaz parfait se détend de façon isotherme de \(V_i\) à \(V_f\). Sa variation d'énergie interne et le travail fourni valent :

  • \(\Delta E = nC_V\Delta T\), \(W = 0\)
  • \(\Delta E = W = nRT\ln(V_f/V_i)\)
  • \(\Delta E = 0\), \(W = nRT\ln(V_f/V_i)\)
  • \(\Delta E = -W = nRT\ln(V_f/V_i)\)
\(E\) ne dépend que de \(T\) pour un gaz parfait (\(T\beta/\kappa = p\)), donc \(\Delta E = 0\) et \(\Delta Q = W = \int p\,dV = nRT\ln(V_f/V_i)\).

Pendant un processus adiabatique quasi statique :

  • \(dQ = 0\) et \(dS = 0\)
  • \(dT = 0\)
  • \(dE = 0\)
  • \(dp = 0\)
Pas d'échange de chaleur, donc \(dS = dQ/T = 0\) : l'entropie est constante. La température, elle, varie (compression adiabatique → échauffement).

Pour l'air (\(\nu = 5\)), la valeur de \(\gamma = (\nu+2)/\nu\) est :

  • 1,67
  • 1,4
  • 2,5
  • 0,71
\(\gamma = 7/5 = 1{,}4\). Pour un gaz monoatomique (\(\nu = 3\)) : \(5/3 = 1{,}67\).

Laquelle de ces relations est fausse pour un gaz parfait en transformation adiabatique ?

  • \(pV^\gamma = \) cste
  • \(TV^{\gamma-1} = \) cste
  • \(T\,p^{1/\gamma-1} = \) cste
  • \(pV = \) cste
\(pV = \) cste caractérise l'isotherme. Les trois autres sont équivalentes grâce à \(pV = NkT\).

Un gaz est comprimé adiabatiquement. Que fait sa température ?

  • Elle augmente
  • Elle diminue
  • Elle reste constante
  • Elle devient nulle
\(dT/T = -(\beta/\kappa C_V)\,dV\) : \(dV \lt 0\) donne \(dT \gt 0\). Le travail reçu augmente l'énergie interne (\(dE = -p\,dV \gt 0\)).

Lors d'une détente libre (dans le vide) d'un gaz parfait :

  • la température diminue fortement
  • la température ne change pas, mais l'entropie augmente
  • l'entropie reste constante car \(\Delta Q = 0\)
  • le gaz fournit un travail \(p\Delta V\)
\(\Delta W = 0\), \(\Delta Q = 0\) donc \(\Delta E = 0\) et \(\Delta T = 0\) pour un gaz parfait. Le processus est irréversible : \(\Delta S = nR\ln(V_f/V_i) \gt 0\). Un gaz réel, lui, se refroidit.

Le taux de transfert de chaleur par conduction à travers une plaque est :

  • \(\dot Q = kA\,\Delta T\,\Delta x\)
  • \(\dot Q = k\,\Delta T/(A\Delta x)\)
  • \(\dot Q = -kA\,\Delta T/\Delta x\)
  • \(\dot Q = kA\,\Delta x/\Delta T\)
Loi de Fourier : proportionnel à l'aire et au gradient, inversement proportionnel à l'épaisseur.

La résistance thermique d'une couche d'épaisseur \(\Delta x\), de conductivité \(k\) et d'aire \(A\) vaut :

  • \(\Delta x/(kA)\)
  • \(kA/\Delta x\)
  • \(k\Delta x/A\)
  • \(A/(k\Delta x)\)
\(R = \Delta x/(kA)\) en K/W, pour que \(\dot Q = \Delta T/R\) comme \(I = V/R\).

Deux couches traversées successivement par le même flux de chaleur se combinent :

  • en parallèle : \(1/R = 1/R_1 + 1/R_2\)
  • en série : \(R = R_1 + R_2\)
  • en moyenne : \(R = (R_1+R_2)/2\)
  • en produit : \(R = R_1R_2\)
Même flux, chutes de température qui s'additionnent → résistances en série. Deux chemins côte à côte soumis au même \(\Delta T\) sont en parallèle.

Dans l'équation de la chaleur \(\partial T/\partial t = K\,\partial^2T/\partial x^2\), la diffusivité \(K\) vaut :

  • \(k\rho_m c\)
  • \(\rho_m c/k\)
  • \(k/c\)
  • \(k/(\rho_m c)\)
\(K = k/(\rho_m c)\) en m²/s : grand pour les métaux (bonne conductivité, faible capacité volumique), petit pour le bois ou l'eau.

Une vitrine est formée de deux vitres de 3 mm séparées par 1 cm d'air immobile. Quelle couche domine la résistance thermique ?

  • La lame d'air (\(k = 0{,}023\) W/(m K))
  • Les deux vitres (\(k = 0{,}95\) W/(m K))
  • Les deux contribuent également
  • Aucune : la résistance ne dépend que de l'aire
\(R = \Delta x/(kA)\) : l'air est 40 fois moins conducteur et 3 fois plus épais, sa résistance est \(0{,}01/0{,}023 = 0{,}43\) contre \(2\times0{,}003/0{,}95 = 0{,}006\) (par m²) : plus de 80 % du total.

D1. Détente isotherme d'un gaz parfait

Un gaz parfait de \(n\) moles subit une détente isotherme de \(V_i\) à \(V_f\) à la température \(T\). (a) Expression du travail effectué par le gaz ? (b) Expression de la chaleur absorbée par le gaz ?

Corrigé
  1. (a) \(\Delta W = \displaystyle\int_{V_i}^{V_f}p\,dV\) avec \(p = \dfrac{nRT}{V}\) : \(\Delta W = nRT\displaystyle\int_{V_i}^{V_f}\frac{dV}{V} = nRT\ln\frac{V_f}{V_i}\).
  2. (b) Isotherme pour un gaz parfait → \(\Delta E = 0\), donc \(\Delta Q = \Delta W = nRT\ln\dfrac{V_f}{V_i}\). Toute la chaleur absorbée ressort en travail ; l'entropie du gaz augmente de \(\Delta Q/T = nR\ln(V_f/V_i)\).

D3. Flux de chaleur venant de l'intérieur de la Terre

En descendant dans la croûte terrestre, la température augmente d'environ 30 °C par kilomètre. (a) Avec la conductivité de la roche (table 12.1), calculer le flux de chaleur par m² qui atteint la surface depuis l'intérieur. (b) Comparer à l'énergie solaire moyenne reçue par la surface terrestre, 175 W/m².

D4. Les relations d'un processus adiabatique

Pour un gaz parfait en transformation adiabatique, montrer que (a) \(pV^\gamma = \) cste (vu en classe) ; (b) \(TV^{\gamma-1} = \) cste ; (c) \(T\,p^{1/\gamma - 1} = \) cste ; (d) \(\gamma = C_p/C_V\).

Corrigé
  1. (a) \(dE = -p\,dV = \frac{N\nu}{2}k\,dT\) et \(p\,dV + V\,dp = Nk\,dT\) → \(\frac{dp}{p} = -\gamma\frac{dV}{V}\) → \(pV^\gamma = \) cste avec \(\gamma = (\nu+2)/\nu\).
  2. (b) \(pV = nRT\) → \(p = nRT/V\) : \((nRT/V)V^\gamma = nRT\,V^{\gamma-1} = \) cste → \(TV^{\gamma-1} = \) cste.
  3. (c) \(V = nRT/p\) : \(T(nRT/p)^{\gamma-1} = \) cste → \(T^\gamma p^{1-\gamma} = \) cste → \(T\,p^{(1-\gamma)/\gamma} = T\,p^{1/\gamma - 1} = \) cste.
  4. (d) Par mole, \(C_V = \frac{\nu}{2}R\) et \(C_p = \frac{\nu}{2}R + p\left(\frac{\partial v}{\partial T}\right)_p = \frac{\nu}{2}R + R = \frac{\nu+2}{2}R\) ; donc \(C_p/C_V = (\nu+2)/\nu = \gamma\).

D5. Combien de degrés de liberté ?

Un gaz est comprimé adiabatiquement : \(p_i = 1\) atm, \(V_i = 2\) L, \(p_f = 1{,}1\) atm, \(V_f = 1{,}85\) L. Nombre de degrés de liberté par molécule ?

Corrigé
\[p_iV_i^\gamma = p_fV_f^\gamma\ \Longrightarrow\ \gamma = \frac{\ln(p_f/p_i)}{\ln(V_i/V_f)} = \frac{\ln 1{,}1}{\ln(2/1{,}85)} = \frac{0{,}0953}{0{,}0780} = 1{,}22\qquad \nu = \frac{2}{\gamma - 1} = 9\]

ν = 9 degrés de liberté (molécule polyatomique)

D6. Même détente, trois processus

0,446 mol d'un gaz parfait à 0 °C, 1 atm, \(V_i = 10{,}0\) L, 5 ddl par molécule, se détend jusqu'à 15 L. Nouvelles température et pression si la détente est (a) isobare ; (b) isotherme ; (c) adiabatique ?

Corrigé
  1. (a) Isobare : \(p_f = 1\) atm ; \(V/T = \) cste → \(T_f = T_i\dfrac{V_f}{V_i} = 273\times1{,}5 = 409{,}5\) K.
  2. (b) Isotherme : \(T_f = 273\) K ; \(pV = \) cste → \(p_f = 1\ \text{atm}\times\dfrac{10}{15} = 0{,}667\) atm = 67,6 kPa.
  3. (c) Adiabatique, \(\gamma = 7/5 = 1{,}4\) : \(p_f = p_i(V_i/V_f)^\gamma = 1\ \text{atm}\times(0{,}667)^{1{,}4} = 0{,}567\) atm = 57,4 kPa ; \(T_f = T_i\dfrac{p_fV_f}{p_iV_i} = 273\times0{,}567\times1{,}5 = 232\) K (ou \(T_f = T_i(V_i/V_f)^{0{,}4}\)).

(a) 409,5 K, 1 atm | (b) 273 K, 67,6 kPa | (c) 232 K, 57,4 kPa

D7. β et κ d'un gaz parfait

Pour un gaz parfait, calculer \(\beta\) et \(\kappa\) en fonction de \(p\), \(T\) et \(V\).

Corrigé
\[V = \frac{nRT}{p}:\qquad \beta = \frac1V\left(\frac{\partial V}{\partial T}\right)_p = \frac1V\cdot\frac{nR}{p} = \frac{nR}{pV} = \frac1T\qquad\qquad \kappa = -\frac1V\left(\frac{\partial V}{\partial p}\right)_T = \frac1V\cdot\frac{nRT}{p^2} = \frac{nRT}{p^2V} = \frac1p\]

β = 1/T, κ = 1/p

D8. Convection ou inversion thermique ?

La pression décroît avec l'altitude selon \(p = p_0e^{-\alpha y}\), \(\alpha = 0{,}116\) km⁻¹ ; pour l'air \(\gamma = 1{,}4\). (a) Si la température au sol vaut 293 K, quelle serait la température à 1 km d'altitude si elle variait au taux adiabatique ? (b) Si la température réelle à 1 km est de 285 K, y a-t-il convection ascendante ou couche d'inversion ?

Corrigé
  1. (a) Adiabatique : \(T\,p^{1/\gamma - 1} = \) cste → \(T_1 = T_0\left(\dfrac{p_1}{p_0}\right)^{1 - 1/\gamma} = T_0\,e^{-\alpha y(\gamma-1)/\gamma} = 293\,e^{-0{,}116\times0{,}286} = 293\times0{,}967 = 283{,}4\) K.
  2. (b) Une parcelle d'air qui monte de 1 km se refroidit à 283,4 K, c'est-à-dire plus que l'air ambiant (285 K) : plus froide donc plus dense, elle redescend. Pas de convection : inversion thermique, qui piège les polluants (smog). Il y aurait convection si l'air ambiant était plus froid que 283,4 K.

(a) 283,4 K | (b) couche d'inversion

dE pour un processus isobare

Processus isobare non diffusif. À partir du premier principe, trouver les expressions qui relient la variation d'énergie interne (a) à la variation de volume ; (b) à la variation de température. Exprimer les dérivées partielles avec la table 11.1.

Corrigé

\(dE = T\,dS - p\,dV\) avec \(dp = 0\), \(dN = 0\).

Isobare avec échange de particules

Processus isobare (\(dp = 0\)), donc deux variables indépendantes. À partir du premier principe, écrire (a) \(dE\) en fonction de \(dV\) et \(dN\) (écrire d'abord \(dS\) en fonction de \(dV\) et \(dN\)) ; (b) \(dE\) en fonction de \(d\mu\) et \(dN\).

Corrigé

Dans \(dE = T\,dS - p\,dV + \mu\,dN\) : \(dE = \left(\dfrac{C_p}{V\beta} - p\right)dV + \left[T\left(\dfrac{\partial S}{\partial N}\right)_{p,V} + \mu\right]dN\).
  2. Chap. 12, ex. 9, p. 245Processus isotherme, expression différentielle

dE pour un processus isotherme

Processus isotherme non diffusif. À partir du premier principe, relier la variation d'énergie interne (a) à la variation de volume ; (b) à la variation de pression.

Corrigé
  1. (a) \(dS = \left(\frac{\partial S}{\partial V}\right)_T dV = \frac{\beta}{\kappa}dV\) → \(dE = \left(\dfrac{T\beta}{\kappa} - p\right)dV\).
  2. (b) \(dS = \left(\frac{\partial S}{\partial p}\right)_T dp = -V\beta\,dp\) et \(dV = \left(\frac{\partial V}{\partial p}\right)_T dp = -V\kappa\,dp\) → \(dE = -TV\beta\,dp + pV\kappa\,dp = (-TV\beta + pV\kappa)\,dp\).

(a) dE = (Tβ/κ − p) dV | (b) dE = (−TVβ + pVκ) dp ; les deux s'annulent pour un gaz parfait

Chap. 12, ex. 43, p. 250Calculs pour différents types d'expansion

Détente libre, adiabatique, isotherme

Un gaz parfait passe de \(V_i\) à \(V_f\), température initiale \(T_i\). Calculer \(\Delta E\), \(\Delta Q\) et \(\Delta W\) en fonction de \(N\), \(\nu\), \(T_i\), \(V_i\), \(V_f\) pour (a) une détente libre ; (b) une détente adiabatique (\(pV^\gamma = \) cste, avec \(p_iV_i = NkT_i\)) ; (c) une détente isotherme.

Corrigé
  1. (a) Détente libre : aucun travail, aucune chaleur : \(\Delta W = \Delta Q = \Delta E = 0\) (et \(\Delta T = 0\) pour un gaz parfait).
  2. (b) Adiabatique : \(\Delta Q = 0\) ; \(T_f = T_i(V_i/V_f)^{\gamma-1}\) ; \(\Delta E = \frac{\nu}{2}Nk(T_f - T_i) = -\dfrac{NkT_i}{\gamma-1}\left[1 - \left(\dfrac{V_i}{V_f}\right)^{\gamma-1}\right]\) (car \(\frac{\nu}{2} = \frac{1}{\gamma-1}\)) ; \(\Delta W = -\Delta E\).
  3. (c) Isotherme : \(\Delta E = 0\), \(\Delta Q = \Delta W = NkT_i\ln(V_f/V_i)\).
Chap. 12, ex. 46, p. 250Nombre d'états et réversibilité

Retirer la cloison entre deux gaz

Un récipient est divisé en deux volumes égaux \(V\) contenant chacun \(N\) particules d'un gaz, avec le même \(\omega_c = c\,(V/N)(E_{therm}/N\nu)^{\nu/2}\). On retire la cloison. Nombre d'états du système combiné (a) avant ; (b) après, si les deux gaz sont différents ; (c) après, si les deux gaz sont identiques. (d) Comment expliquer ce dernier résultat : si le volume par particule double, \(\omega_c\) ne devrait-il pas doubler ?

Corrigé
  1. (a) \(\Omega_0 = \Omega_1\Omega_2 = \omega_c^N\omega_c^N = \omega_c^{2N}\).
  2. (b) Gaz différents : chaque gaz dispose maintenant de \(2V\) avec le même \(N\) : \(\omega_c' = 2\omega_c\), donc \(\Omega_0 = (2\omega_c)^{2N} = 2^{2N}\omega_c^{2N}\). L'entropie augmente de \(2Nk\ln 2\) : le mélange est irréversible.
  3. (c) Gaz identiques : un seul système de \(2N\) particules dans \(2V\) avec \(2E_{therm}\) : \(\omega_c = c\,\dfrac{2V}{2N}\left(\dfrac{2E_{therm}}{2N\nu}\right)^{\nu/2}\) inchangé, donc \(\Omega_0 = \omega_c^{2N}\) : pas de changement.
  4. (d) Le volume par particule \(V/N\) ne change pas (deux fois plus de volume pour deux fois plus de particules) ; comme les particules sont identiques, les échanger ne crée aucun nouvel état. Rien ne change quand on remet la cloison : le processus est réversible (paradoxe de Gibbs).
