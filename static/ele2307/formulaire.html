Cours 1 - Statistique des systèmes

Moyenne

\(\displaystyle\bar f = \sum_{i=1}^{n} p_i f_i\)

\(\overline{f+g} = \bar f + \bar g\) ; \(\overline{(cf)} = c\bar f\) pour \(c\in\mathbb R\)

\(\overline{fg} = \bar f\cdot\bar g\)

\(\bar n = pN\)

\(p_i\) : probabilité de l’état \(i\), \(\sum p_i = 1\)

toujours vrai (linéarité)

pour des variables indépendantes

nombre moyen d’éléments satisfaisant le critère, grand \(N\)

Critère unique

\(p + q = 1\)

Critères indépendants : \(P = P_1\,P_2\)

 \(p\) : critère satisfait, \(q\) : non satisfait. Penser au complémentaire \(1-P\).
Dénombrement

\(\displaystyle C_N^n = \binom{N}{n} = \frac{N!}{n!\,(N-n)!}\)

\(\displaystyle A_N^n = \frac{N!}{(N-n)!} = N(N-1)\cdots(N-n+1)\)

\(N!\) permutations de \(N\) éléments distincts

tirage simultané (l’ordre ne compte pas)

tirage successif, ordre compté (\(= n!\,C_N^n\))

\(0! = 1! = 1\)

Loi binomiale \(\displaystyle P_N(n) = \frac{N!}{n!\,(N-n)!}\,p^{\,n}q^{\,N-n}\) exactement \(n\) éléments sur \(N\) satisfont le critère ; éléments indépendants
Critères multiples \(\displaystyle P_N(n_1,n_2,\ldots,n_m) = \frac{N!}{n_1!\,n_2!\cdots n_m!}\,p_1^{\,n_1}p_2^{\,n_2}\cdots p_m^{\,n_m}\) critères mutuellement exclusifs ; \(n_1+\cdots+n_m = N\) et \(p_1+\cdots+p_m = 1\)
Formule de Stirling

\(\displaystyle m! \approx \sqrt{2\pi m}\left(\frac{m}{e}\right)^{m}\)

\(\ln(m!) \approx m\ln m - m + \tfrac12\ln(2\pi m)\)

\(m! \approx 10^{\,0{,}4343\,(m\ln m - m + \frac12\ln 2\pi m)}\)

grands \(m\) (erreur < 1 % dès \(m\ge10\))

forme simplifiée pour \(m\) énorme : \(\ln m!\approx m\ln m - m\), soit \(m!\approx(m/e)^m\)

Écart type

\(\displaystyle\sigma = \sqrt{\overline{(f-\bar f)^2}}\) ; \(\text{Variance} = \sigma^2 = \overline{f^2}-\bar f^{\,2}\)

\(\text{Variance}(f+g) = \text{Variance}(f)+\text{Variance}(g)\)

\(\sigma = \sqrt{Npq}\) ; \(\displaystyle\frac{\sigma}{\bar n} = \sqrt{\frac{q}{pN}}\propto\frac{1}{\sqrt N}\)

définition générale

variables indépendantes (les variances s’additionnent, pas les \(\sigma\))

pour le critère unique ; fluctuation relative

Loi gaussienne

\(\displaystyle P_N(n) = \frac{1}{\sqrt{2\pi}\,\sigma}\,e^{-\frac{(n-\bar n)^2}{2\sigma^2}} = A\,e^{-B(n-\bar n)^2}\)

\(\displaystyle A = \frac{1}{\sqrt{2\pi}\sigma} = P_N(\bar n)\),   \(\displaystyle B = \frac{1}{2\sigma^2}\)

\(p_\sigma\approx0{,}68\), \(p_{2\sigma}\approx0{,}95\), \(p_{3\sigma}\approx0{,}997\)

approximation de la binomiale pour un très grand nombre d’éléments, avec \(\bar n = pN\), \(\sigma = \sqrt{Npq}\) ; aire totale = 1

probabilité d’être à moins de \(\sigma\), \(2\sigma\), \(3\sigma\) de la moyenne

Marche aléatoire

\(\overline{S_n} = n\,\bar s\)  et  \(\sigma_n = \sigma\sqrt n\)

\(\displaystyle p_n(L) = C_n^{\,k}\,p_d^{\,k}p_g^{\,n-k}\), \(k = \frac{L+n}{2}\)

Pas 3D de longueur \(a\), direction aléatoire : \(\bar s_z = 0\), \(\sigma_z = a/\sqrt3\)

\(\bar s\), \(\sigma\) : moyenne et écart type d’une seule étape ; \(n\) étapes

pas de même longueur, \(L\) et \(n\) de même parité

projection sur un axe : \(\overline{\cos^2\theta} = 1/3\)

Cours 2 - Énergie interne et états accessibles

Formes d’énergie

\(u(x) = u_0 + \tfrac12\kappa x^2\)

\(\displaystyle\varepsilon_c = \frac{p^2}{2m} = \frac{p_x^2+p_y^2+p_z^2}{2m}\) ; \(\displaystyle\varepsilon_{r,i} = \frac{L_i^2}{2I_i}\)

\(\displaystyle\varepsilon = u_0 + \sum_{\text{ddl}}\beta\xi^2\),   \(\displaystyle\varepsilon_{therm} = \sum_{\text{ddl}}\beta\xi^2\)

potentielle près de l’équilibre (\(u_0\lt0\) si liée)

cinétique ; rotation (\(L\) moment cinétique, \(I\) moment d’inertie)

chaque terme \(\beta\xi^2\) = un degré de liberté

Degrés de liberté \(\nu\)

Gaz monoatomique : \(\nu = 3\) (translations)

Gaz diatomique : \(\nu = 5\) (3 translations + 2 rotations)

Solide : \(\nu = 6\) (3 cinétiques + 3 potentiels)

 \(\nu = 3\) à très basse \(T\) et \(\nu = 7\) à très haute \(T\) (vibration) pour un gaz diatomique ; ddl gelés si \(kT\ll\) énergie du 1er état excité
Équipartition

\(\overline{\varepsilon_{\text{ddl}}} = \tfrac12kT\) ; \(\displaystyle\varepsilon_{therm} = \frac{\nu}{2}kT\)

\(\displaystyle E_{therm} = \frac{N\nu}{2}kT\) ; \(\displaystyle E = Nu_0 + \frac{N\nu}{2}kT\)

\(\displaystyle \frac{\overline{p^2}}{2m} = \frac32kT\ \Rightarrow\ p_{rms} = \sqrt{3mkT},\ v_{rms} = \sqrt{\frac{3kT}{m}}\)

par ddl ; par particule

pour le système ; énergie interne totale

3 ddl de translation (estimation \(p_0\approx2p_{rms}\) dans les exercices)

Travail

\(\Delta W = F\Delta x\) ; \(\Delta W = p\Delta V\)  (\(\displaystyle\Delta W = \int p\,dV\))

\(\Delta W = -\vec B\cdot\Delta\vec\mu\) ; \(\Delta W = -\vec E\cdot\Delta\vec p\)

 travail fourni par le système ; \(\mu\) moment magnétique, \(p\) moment dipolaire électrique
1re loi de la thermodynamique

\(\Delta E = \Delta Q - \Delta W + \mu\Delta N\)

\(\Delta E_1 = \mu_1\Delta N\), \(\Delta E_2 = -\mu_2\Delta N\)

 \(\Delta Q\) reçue, \(\Delta W\) fournie par le système, \(\Delta N\) reçues ; \(\mu\) potentiel chimique. Chaleur : conduction, radiation, convection
Nombre d’états

\(\Omega = \omega\times\omega\times\cdots = \omega^N\)

\(\displaystyle\Omega = \frac{\omega^N}{N!}\approx\left(\frac{e\omega}{N}\right)^N = \omega_c^{\,N}\),   \(\displaystyle\omega_c = \frac{e\omega}{N}\)

\(\Omega(E,\Delta E) = g(E)\,\Delta E\) ; \(\Omega_{A+B} = \Omega_A\Omega_B\)

particules distinctes

particules identiques (Stirling : \(N!\approx(N/e)^N\))

densité d’états \(g(E) = d\Omega/dE\) ; systèmes combinés

Équiprobabilité \(\displaystyle p_{\text{un état}} = \frac{1}{\Omega}\) ; \(\displaystyle P_i = \frac{\Omega_i}{\Omega}\) à l’équilibre, tous les états accessibles sont équiprobables
Discrétisation (Heisenberg)

\(\Delta x\,\Delta p_x\ge h\)

\(\displaystyle\omega = \frac{[x][p_x]}{h}\) (1D) ; \(\displaystyle\omega = \frac{V_rV_p}{h^3}\) (3D)

\(\displaystyle\omega = \frac{V}{h^3}\iiint dp^3 = \frac{4\pi V}{3h^3}\left(p_2^3 - p_1^3\right)\)

un état occupe au minimum \(h\) (1D) ou \(h^3\) (3D)

\(V_p = \tfrac43\pi p_0^3\) pour \(0\le p\le p_0\)

Nombre d’états accessibles

Gaz : \(\displaystyle\omega_c\propto\frac{V}{N}\left(\frac{E_{therm}}{N\nu}\right)^{\nu/2}\),   \(\displaystyle\Omega = \omega_c^N\propto\left(\frac{V}{N}\right)^N\left(\frac{E_{therm}}{N\nu}\right)^{N\nu/2}\)

Solide : \(\displaystyle\omega_c\propto\left(\frac{E_{therm}}{N\nu}\right)^{\nu/2}\),   \(\displaystyle\Omega = \omega_c^N\propto\left(\frac{E_{therm}}{N\nu}\right)^{N\nu/2}\)

\(g(E)\propto\) mêmes expressions ; avec \(E_{therm} = N\nu kT/2\) : \(g\propto(V/N)^N(kT/2)^{N\nu/2}\) (gaz)

correction \(e/N\) seulement pour les gaz

solide : particules localisées, pas de facteur \(V\)

Comparer deux états du système \(\displaystyle\log_{10}\frac{\Omega_f}{\Omega_i} = \frac{N\nu}{2}\log_{10}\frac{E_f}{E_i} + N\log_{10}\frac{V_f}{V_i}\) \(E_f/E_i = T_f/T_i\) si \(u_0\) constant ; réponse sous la forme \(10^{(\ldots)}\)

Cours 3 - Entropie et interaction thermique

Interaction entre systèmes

\(E_1 + E_2 = E_0\) ; \(\Omega_0 = \Omega_1\Omega_2 \propto E_1^{n_1/2}(E_0 - E_1)^{n_2/2}\)

\(\displaystyle E_1^* = \frac{n_1}{n_1+n_2}E_0\)

 \(n = N\nu\) : ddl de chaque système ; répartition la plus probable (maximum de \(\Omega_0\)), pic de largeur relative \(\propto 1/\sqrt{n_1+n_2}\)
Entropie

\(S = k\ln\Omega\) ; \(S_0 = S_1 + S_2\)

\(\displaystyle\left(\frac{\partial S}{\partial V}\right)_{E,N} = \frac{p}{T}\) ; \(\displaystyle\left(\frac{\partial S}{\partial N}\right)_{E,V} = -\frac{\mu}{T}\) ; \(dQ = T\,dS\)

 additive car \(\Omega_0 = \Omega_1\Omega_2\) ; dérivées issues de \(dS = dE/T + (p/T)dV - (\mu/T)dN\) ; \(dQ = TdS\) à \(V\), \(N\) constants
2e loi de la thermodynamique \(\Delta\Omega \ge 0\) ; \(\Delta S_0 \ge 0\) système isolé ; maximum à l'équilibre, variations nulles
Définition de la température \(\displaystyle\left(\frac{\partial S}{\partial E}\right)_{V,N} = \frac{1}{T}\) équilibre thermique \(dS_0 = 0 \Leftrightarrow T_1 = T_2\) ; la chaleur va du chaud vers le froid
Énergie thermique (équipartition) \(\displaystyle\frac{E_{therm}}{N\nu} = \frac12kT\) ; \(\displaystyle E_{therm} = \frac{N\nu}{2}kT\) démontré avec \(1/T = dS/dE\) sur \(\Omega\propto E_{therm}^{N\nu/2}\)
Nombre d'états et chaleur ou entropie

\(\displaystyle\Delta S = S_f - S_i = k\ln\Omega_f - k\ln\Omega_i = k\ln\frac{\Omega_f}{\Omega_i}\)

\(\displaystyle\frac{\Omega_f}{\Omega_i} = e^{\Delta S/k} = e^{\Delta Q/kT}\)

 \(T\) constante pendant l'échange ; \(e^x = 10^{0{,}4343x}\)
Capacité thermique

\(\displaystyle C_y = \left(\frac{dQ}{dT}\right)_y\) ; molaire \(C = C_y/n\) ; chaleur spécifique \(c = C_y/m\)

\(\displaystyle\Delta S = \int\frac{C\,dT}{T} = m\,c\ln\frac{T_f}{T_i}\) ; \(\displaystyle\Delta S_{phase} = \frac{Q_{latente}}{T_{phase}}\)

 \(y = p\) (pression constante) ou \(V\) ; \(c\) supposée constante ; table 8.1 (eau 4,19 kJ/(kg K))
Loi des gaz parfaits \(pV = NkT\) ; \(pV = nRT\) (forme molaire) \(R = N_Ak = 8{,}314\) J/(mol K) ; obtenue de \((\partial S/\partial V)_{E,N} = p/T\)
Capacités d'un gaz parfait \(\displaystyle C_V = \frac{\nu}{2}R\) ; \(C_p = C_V + R\) ; \(\displaystyle\gamma = \frac{C_p}{C_V} = \frac{\nu+2}{\nu}\) par mole ; chap. 8, ex. 41
3e loi de la thermodynamique

\(S(T = 0\ \text{K}) = 0\) J/K

\(\displaystyle S(T) = \int_0^T\frac{dQ}{T'} = \int_0^T\frac{C_p(T')\,dT'}{T'}\)

 \(\Omega = 1\) à 0 K ; \(C_p \to 0\) quand \(T\to0\) ; ex. \(C = a\sqrt T \Rightarrow S = 2a\sqrt T\)
Chaleur d'une réaction \(\Delta S = S_{produits} - S_{réactifs}\) ; \(\Delta Q = T\,\Delta S\) à \(T\) constante ; \(\Delta Q \lt 0\) : exothermique

Cours 4 - Les processus thermodynamiques

Coefficients \(\displaystyle\kappa = -\frac1V\left(\frac{\partial V}{\partial p}\right)_T\) (compressibilité isotherme) ; \(\displaystyle\beta = \frac1V\left(\frac{\partial V}{\partial T}\right)_p\) (expansion thermique) gaz parfait : \(\beta = 1/T\), \(\kappa = 1/p\)
Dérivées partielles (processus non diffusifs)

\(\displaystyle\left(\frac{\partial S}{\partial T}\right)_p = \frac{C_p}{T}\) ; \(\displaystyle\left(\frac{\partial S}{\partial V}\right)_T = \frac{\beta}{\kappa}\) ; \(\displaystyle\left(\frac{\partial T}{\partial V}\right)_S = -\frac{T\beta}{C_V\kappa}\)

\(\displaystyle\left(\frac{\partial S}{\partial T}\right)_V = \frac{C_V}{T}\) ; \(\displaystyle\left(\frac{\partial S}{\partial V}\right)_p = \frac{C_p}{TV\beta}\) ; \(\displaystyle\left(\frac{\partial T}{\partial V}\right)_p = \frac{1}{V\beta}\)

\(\displaystyle\left(\frac{\partial S}{\partial p}\right)_T = -V\beta\) ; \(\displaystyle\left(\frac{\partial T}{\partial p}\right)_S = \frac{TV\beta}{C_p}\) ; \(\displaystyle\left(\frac{\partial p}{\partial V}\right)_S = -\frac{C_p}{VC_V\kappa}\)

\(\displaystyle\left(\frac{\partial S}{\partial p}\right)_V = \frac{C_V\kappa}{T\beta}\) ; \(\displaystyle\left(\frac{\partial T}{\partial p}\right)_V = \frac{\kappa}{\beta}\) ; \(\displaystyle\left(\frac{\partial p}{\partial V}\right)_T = -\frac{1}{V\kappa}\)

 table 11.1 du manuel ; \(C_p\), \(C_V\) du système entier ; choisir la dérivée dont la variable fixée est celle du processus
Processus isobares

\(dE = (C_p - pV\beta)\,dT\)

gaz parfait : \(W = p\Delta V = nR\Delta T\) ; \(Q = nC_p\Delta T\) ; \(\Delta E = nC_V\Delta T\) ; \(\displaystyle\Delta S = nC_p\ln\frac{T_f}{T_i}\) ; \(\displaystyle\frac{T_f}{T_i} = \frac{V_f}{V_i}\)

 \(dp = 0\), \(dN = 0\)
Processus isothermes

\(\displaystyle dE = \left(\frac{T\beta}{\kappa} - p\right)dV\) ; \(\displaystyle dE = \left(T - \frac{p\kappa}{\beta}\right)dS\)

gaz parfait : \(\Delta E = 0\) ; \(\displaystyle Q = W = nRT\ln\frac{V_f}{V_i}\) ; \(\displaystyle\Delta S = nR\ln\frac{V_f}{V_i}\) ; \(\displaystyle\frac{V_f}{V_i} = \frac{p_i}{p_f}\)

 \(dT = 0\), \(dN = 0\)
Processus isochores \(W = 0\) ; \(Q = \Delta E = nC_V\Delta T\) ; \(\displaystyle\Delta S = nC_V\ln\frac{T_f}{T_i}\) ; \(\displaystyle\frac{T_f}{T_i} = \frac{p_f}{p_i}\) \(dV = 0\) ; gaz parfait
Processus adiabatiques

\(\displaystyle\frac{dT}{T} = \frac{V\beta}{C_p}dp\) ; \(\displaystyle\frac{dT}{T} = -\frac{\beta}{\kappa C_V}dV\) ; \(\displaystyle\frac{dV}{V} = -\frac{\kappa C_V}{C_p}dp\)

\(pV^\gamma = \) cste où \(\displaystyle\gamma = \frac{\nu+2}{\nu}\) ; \(TV^{\gamma-1} = \) cste ; \(T\,p^{1/\gamma-1} = \) cste

\(Q = 0\) ; \(\Delta S = 0\) ; \(\displaystyle W = -\Delta E = \frac{p_iV_i - p_fV_f}{\gamma-1} = nC_V(T_i - T_f)\)

 \(dQ = 0\) donc \(dS = 0\) ; \(T\uparrow \Rightarrow p\uparrow\), \(T\uparrow \Rightarrow V\downarrow\), \(V\uparrow \Rightarrow p\downarrow\) ; gaz parfait pour les formules en \(\gamma\)
Détente libre \(\displaystyle\Delta T = \left(\frac{p\kappa - T\beta}{\kappa C_V}\right)\Delta V\) \(\Delta E = 0\), \(\Delta W = 0\) ; \(= 0\) pour un gaz parfait, refroidit un gaz réel ; \(\Delta S \gt 0\)
Conduction thermique

\(\displaystyle\frac{\Delta Q}{\Delta t} = -kA\frac{\Delta T}{\Delta x}\) ; \(\displaystyle j_Q = -k\frac{\Delta T}{\Delta x}\)

Résistance thermique \(\displaystyle R = \frac{\Delta x}{kA}\) ; \(\displaystyle\dot Q = \frac{\Delta T}{R}\) ; série \(R = \sum R_i\) ; parallèle \(\displaystyle\frac1R = \sum\frac1{R_i}\)

 \(k\) en W/(m K) (table 12.1 : cuivre 380, verre 0,95, air 0,023) ; \(R\) en K/W
Équation de la chaleur

\(\displaystyle\frac{\partial E}{\partial t} = -A\frac{\partial j_Q}{\partial x}\Delta x\) ou \(\displaystyle\frac{\partial\rho_E}{\partial t} = -\frac{\partial j_Q}{\partial x}\)

\(\displaystyle\frac{\partial^2T}{\partial x^2} = \frac1K\frac{\partial T}{\partial t}\) où \(\displaystyle K = \frac{k}{\rho_m c}\)

 \(d\rho_E = \rho_m c\,dT\) ; \(K\) : diffusivité (m²/s) ; étalement \(\sim\sqrt{Kt}\), temps \(\sim L^2/K\)

Cours 6 - Gestion de la chaleur dans les systèmes électroniques

Loi de Fourier \(\displaystyle\dot Q_{cond} = kA\frac{T_H - T_B}{L} = \frac{T_H - T_B}{R_{cond}}\) où \(\displaystyle R_{cond} = \frac{L}{kA}\) 1D, régime permanent, \(k\) constante, sans source ; \(k\) en W/(m K)
Loi de Newton \(\displaystyle\dot Q_{conv} = hA(T_H - T_B) = \frac{T_H - T_B}{1/(hA)} = \frac{T_H - T_B}{R_{conv}}\) où \(\displaystyle R_{conv} = \frac{1}{hA}\) \(h\) en W/(m² K), dépend du fluide, de la géométrie et de l'écoulement (ordre de 10)
Transfert thermique par rayonnement \(\dot Q_{rad} = \varepsilon\,\sigma\,A\,(T_H^4 - T_B^4)\) \(\sigma = 5{,}67\times10^{-8}\) W/(m² K⁴) ; \(0 \le \varepsilon \le 1\) ; \(T\) en K ; négligeable en électronique

Parallèle : \(\displaystyle\frac{1}{R_{total}} = \frac{1}{R_1} + \frac{1}{R_2}\)

\(\displaystyle\dot Q = \frac{T_i - T_j}{R_{total,\,i-j}}\)

Cours 7 - La statistique quantique

Probabilité d'un état (petit système dans un réservoir) \(\displaystyle P_s = C\exp\!\left(-\frac{\Delta E + p\,\Delta V - \mu\,\Delta N}{kT}\right)\) ; \(\displaystyle \sum_s P_s = 1\) \(\Delta E, \Delta V, \Delta N\) pris au réservoir \((T, p, \mu)\) ; vient de \(S_R = S_{R0} - (\Delta E + p\Delta V - \mu\Delta N)/T\) et \(\Omega_R = e^{S_R/k}\)
Cas classique (Boltzmann)

\(P_s = C e^{-\beta\varepsilon_s}\) avec \(\beta = 1/kT\) et \(\displaystyle C = \frac{1}{\sum_s e^{-\beta\varepsilon_s}}\)

\(\displaystyle \frac{P_i}{P_j} = e^{-\beta(\varepsilon_i - \varepsilon_j)}\)

Niveaux \(\varepsilon_n = n\varepsilon\) : \(C = 1 - e^{-\beta\varepsilon}\)

 particules en nombre fixe (\(\Delta N = 0\)), \(p\upsilon_s \ll \varepsilon_s\) ; le niveau de référence des énergies n'a pas d'importance ; \(kT = 0{,}0253\) eV à 293 K, \(k = 8{,}617\times10^{-5}\) eV/K
Cas quantique (un état, \(n\) particules)

\(P_n = C e^{-n\beta(\varepsilon - \mu)} = Ce^{-nx}\), \(x = \beta(\varepsilon - \mu)\), \(\displaystyle C = \frac{1}{\sum_n e^{-nx}}\)

Fermions (\(n = 0, 1\)) : \(\displaystyle C = \frac{1}{1 + e^{-x}}\) ; bosons (\(n \ge 0\), \(x \gt 0\)) : \(C = 1 - e^{-x}\)

 état de volume fixe (\(\Delta V = 0\)) ; \(\varepsilon\) énergie d'une particule dans l'état, \(\mu\) potentiel chimique ; \(P_1/P_0 = e^{-x}\)
Niveaux dégénérés et bandes

\(P(\varepsilon_s) = n_s P_s\) ; \(\displaystyle \frac{P(\varepsilon_i)}{P(\varepsilon_j)} = \frac{n_i}{n_j}e^{-\beta(\varepsilon_i - \varepsilon_j)}\)

\(\displaystyle P_{bande} = \int_{bande} g(\varepsilon)P(\varepsilon)\,d\varepsilon\)

 \(n_s\) : nombre d'états de même énergie ; \(g(\varepsilon)\) densité d'états ; une bande étroite devant \(kT\) se traite comme un niveau dégénéré
Température d'excitation \(\displaystyle T_e = \frac{\varepsilon_1 - \varepsilon_0}{k}\) ; \(\displaystyle \frac{P_1}{P_0} = e^{-T_e/T}\) \(T \ll T_e\) : système confiné au fondamental, le degré de liberté est gelé ; \(C_V = \tfrac{\nu}{2}R\) avec \(\nu\) qui passe 3 → 5 → 7 (gaz diatomique) ; solides : loi de Dulong et Petit \(C_V = 3R\)
Équipartition

\(\displaystyle \bar\varepsilon = \sum_s P_s\varepsilon_s = \frac{\int e^{-\beta b\xi^2} b\xi^2\,d\xi}{\int e^{-\beta b\xi^2}\,d\xi} = \frac{1}{2\beta} = \frac{1}{2}kT\)

\(\varepsilon = b|\xi|^{\alpha}\) : \(\bar\varepsilon = kT/\alpha\)

 par degré de liberté quadratique (position ou quantité de mouvement) ; vrai pour un système classique
Vitesse quadratique moyenne (mouvement brownien) \(\displaystyle \bar\varepsilon_{trans} = \tfrac{1}{2}m\overline{v^2} = \tfrac{3}{2}kT\) ; \(\displaystyle v_{rms} = \sqrt{\overline{v^2}} = \sqrt{\frac{3kT}{m}}\) 3 degrés de liberté de translation ; en 2D (particule à une surface) \(v_{rms} = \sqrt{2kT/m}\) ; distance parcourue en un temps \(t\) : environ \(v_{rms}t\)
Nombre d'occupation

\(\displaystyle \bar n = \sum_n nP_n = -\frac{\partial}{\partial x}\ln\!\left(\sum_n e^{-nx}\right)\), \(x = \beta(\varepsilon - \mu)\)

\(\displaystyle \bar n_{fermions} = \frac{1}{e^{x} + 1}\) ; \(\displaystyle \bar n_{bosons} = \frac{1}{e^{x} - 1}\) ; \(\displaystyle \bar n = \frac{1}{e^{\beta(\varepsilon-\mu)} \pm 1}\)

 + fermions (Fermi-Dirac, spin demi-entier : e, trou, p, n, μ), − bosons (Bose-Einstein, spin entier : photon, α, deutéron, He-4, π) ; fermions : \(\bar n = 1/2\) à \(\varepsilon = \mu\) ; bosons : il faut \(\mu \lt \varepsilon\) ; la somme se tronque pour d'autres règles d'occupation (0, 1, 2 : « goofions »)
Fluctuations \(\sigma^2 = \overline{n^2} - \bar n^2 = \bar n(1 \mp \bar n)\) − fermions (petites sauf près de \(\mu\)), + bosons (plus grandes que \(\bar n\))
Cas classique et comparaison

\(\displaystyle \bar n_{classique} = NP_s = NCe^{-\beta\varepsilon_s}\) ; \(\displaystyle e^{\beta\mu} = \frac{N}{\sum_s e^{-\beta\varepsilon_s}}\)

\(\varepsilon - \mu \gg kT\) : \(\bar n_{cl} \approx \bar n_B \approx \bar n_F \approx e^{-\beta(\varepsilon - \mu)}\)

\(\varepsilon - \mu \lesssim kT\) : \(\bar n_{bosons} \gt \bar n_{classique} \gt \bar n_{fermions}\)

 haute énergie ou faible occupation : les trois statistiques coïncident ; à basse énergie elles diffèrent à cause du comptage des occupations multiples
Comptage des arrangements (\(n\) particules, \(m\) états) \(\Omega_D = m^n\) ; \(\Omega_{cl} = m^n/n!\) ; \(\Omega_{bosons} = C_{n+m-1}^{\,n}\) ; \(\Omega_{fermions} = C_m^{\,n}\) 2 particules, 2 états : 4 / 2 / 3 / 1 ; 3 particules, 3 états : 27 / 4,5 / 10 / 1 ; la correction \(1/n!\) est exacte pour l'occupation simple seulement
Limite du cas classique

\(\displaystyle \frac{V_rV_p}{h^3} \gg N\) → \(\displaystyle \frac{rp}{h} \gg 1\) avec \(\displaystyle r \approx \left(\frac{V}{N}\right)^{1/3}\), \(p \approx \sqrt{3mkT}\)

 nombre d'états quantiques ≫ nombre de particules ; équivaut à \(r \gg h/p\) (longueur d'onde de de Broglie) ; N₂ de l'air : 120 (classique) ; électrons du cuivre : 0,04 (dégénéré)
Potentiel chimique (complément)

\(\displaystyle N = \sum_s \bar n_s\) ; faible densité : \(\displaystyle \mu = kT\ln\frac{N}{\sum_s e^{-\beta\varepsilon_s}}\)

Bosons dégénérés : \(\mu \approx -kT/N\) ; fermions dégénérés : \(\displaystyle \mu_{T=0} = \varepsilon_F \approx \frac{h^2}{2m}\left(\frac{N}{V}\right)^{2/3}\)

 \(\mu\) est fixé par le nombre total de particules ; \(\varepsilon_F\) énergie de Fermi (cuivre : ordre de 10 eV, soit \(10^5\) K)

Cours 8 - Gaz quantique et radiation du corps noir

Spin et dégénérescence Fermions : \(S = \pm\tfrac{1}{2}\hbar\), 2 orientations ; bosons massifs de spin 1 : \(2s + 1 = 3\) ; photon (sans masse) : 2 polarisations facteur \(2_{spin}\) (ou \(2s+1\)) devant la densité d'états ; deux électrons de spins opposés par état d'énergie
Densité d'états d'un gaz

\(\displaystyle \sum_{\text{états}} = \frac{4\pi V}{h^3}\int p^2\,dp\)

Non relativiste (\(\varepsilon = p^2/2m\)) : \(\displaystyle g(\varepsilon) = 2_{spin}\,\frac{2\pi V(2m)^{3/2}}{h^3}\sqrt{\varepsilon}\)

Relativiste (\(\varepsilon = pc\)) : \(\displaystyle g(\varepsilon) = 2_{spin}\,\frac{4\pi V}{h^3c^3}\varepsilon^2\)

 \(g(\varepsilon)\,d\varepsilon\) = nombre d'états entre \(\varepsilon\) et \(\varepsilon + d\varepsilon\) ; forme générale \(g = C\varepsilon^{\alpha}\), \(\alpha = 1/2\) ou 2
Distribution des particules

\(\displaystyle \frac{dN}{d\varepsilon} = g(\varepsilon)\,\bar n(\varepsilon) = \frac{C\varepsilon^{\alpha}}{e^{\beta(\varepsilon - \mu)} \pm 1}\) ; \(\displaystyle \frac{dE}{d\varepsilon} = \varepsilon\,g\,\bar n\)

\(\displaystyle \bar f = \frac{1}{N}\int f(\varepsilon)\,g(\varepsilon)\,\bar n(\varepsilon)\,d\varepsilon\)

 + fermions, − bosons ; basses énergies \(dN/d\varepsilon \approx \varepsilon^{\alpha}\), hautes énergies \(\approx e^{-\beta\varepsilon}\) ; fermions à basse \(T\) : plein jusqu'à \(\mu\)
Photons \(\varepsilon = h\nu = hc/\lambda\) ; bosons, \(\mu = 0\) ; \(\displaystyle g(\varepsilon) = \frac{8\pi V}{h^3c^3}\varepsilon^2\) \(\mu = 0\) car le nombre de photons n'est pas conservé : \(\mu = -T(\partial S/\partial N)_{E,V} = 0\) à l'équilibre ; \(hc = 1240\) eV nm
Loi de Planck (densité spectrale d'énergie)

\(\displaystyle du = \frac{dE}{V} = \frac{8\pi}{h^3c^3}\,\frac{\varepsilon^3\,d\varepsilon}{e^{\beta\varepsilon} - 1}\)

\(\displaystyle \frac{du}{d\lambda} = 8\pi hc\,\frac{\lambda^{-5}}{e^{hc/\lambda kT} - 1}\)

 \(u\) : énergie par unité de volume ; passage \(\varepsilon \to \lambda\) avec \(|d\varepsilon| = (hc/\lambda^2)\,d\lambda\) ; limite classique (Rayleigh-Jeans) \(8\pi kT\lambda^{-4}\) diverge aux courtes \(\lambda\)
Densité totale d'énergie \(\displaystyle u = \frac{8\pi(kT)^4}{h^3c^3}\int_0^{\infty}\frac{x^3\,dx}{e^x - 1} = \frac{8\pi^5k^4}{15h^3c^3}T^4 = aT^4\), \(a = 7{,}56\times10^{-16}\) J/(m³ K⁴) \(\displaystyle \int_0^{\infty}\frac{x^3dx}{e^x - 1} = \frac{\pi^4}{15}\) ; \(E = aVT^4\) pour une cavité de volume \(V\)
Loi du déplacement de Wien

\(\displaystyle \lambda_{max} = \frac{hc}{4{,}965\,kT} \approx \frac{hc}{5kT} = \frac{2{,}90\times10^{-3}\ \text{m K}}{T}\)

Maximum de \(du/d\varepsilon\) : \(\varepsilon_{max} = 2{,}82\,kT\), soit \(\lambda = 5{,}1\times10^{-3}\ \text{m K}/T\)

 Soleil 5800 K : 500 nm ; corps humain 310 K : 9,3 µm ; fond cosmologique 2,7 K : 1,1 mm ; les maximums en \(\lambda\) et en \(\varepsilon\) ne coïncident pas
Flux d'énergie, loi de Stefan-Boltzmann \(\displaystyle J = u_zv_z = \frac{u}{2}\cdot\frac{c}{2} = \frac{ca}{4}T^4 = \sigma T^4\), \(\sigma = \frac{ca}{4} = 5{,}67\times10^{-8}\) W/(m² K⁴) moitié des photons vers la surface, \(\overline{\cos\theta} = 1/2\) sur un hémisphère ; \(P = JA\) ; Soleil 5800 K : \(6{,}4\times10^{7}\) W/m²
Flux à distance d'une source sphérique \(\displaystyle J(d) = \frac{P}{4\pi d^2} = J_{surface}\left(\frac{R}{d}\right)^2\) Soleil vu de la Terre : \(1{,}4\) kW/m² ; une planète intercepte \(\pi R^2 J\) et rayonne sur \(4\pi R^2\)
Émissivité \(J = e\,\sigma T^4\), \(0 \le e(T, \varepsilon) \le 1\) ; échange net : \(J_{net} = e\,\sigma(T^4 - T_{env}^4)\) ; \(\Delta T \ll T\) : \(J_{net} \approx 4e\sigma T^3\,\Delta T\) bilan détaillé : à l'équilibre, absorbé = émis à chaque longueur d'onde (bon absorbeur = bon émetteur, Stewart 1858, Kirchhoff) ; corps noir \(e = 1\) ; loi de Newton du refroidissement
Écrans thermiques (feuilles) \(\displaystyle J_{n\ \text{feuilles}} = \frac{1}{n+1}\,e\sigma(T_0^4 - T_{n+1}^4)\) ; \(T_i^4\) régulièrement espacés entre \(T_0^4\) et \(T_{n+1}^4\) même flux à travers chaque couche en régime permanent ; vêtements en couches, isolants multicouches
Effet de serre \(\displaystyle J_o = \frac{J_i}{1 - x/2} = \frac{2}{2 - x}J_i\) ; \(\displaystyle T_{sol} = T_0\left(\frac{2}{2 - x}\right)^{1/4}\) \(J_i\) flux absorbé par le sol, \(x\) fraction de l'infrarouge sortant absorbée par la couche, réémise moitié vers le haut, moitié vers le bas ; Terre : 236 K sans atmosphère, 280 K pour \(x = 1\)
Gaz de photons (complément) \(C_V = 4aVT^3\) ; \(S = \tfrac{4}{3}aVT^3\) ; adiabatique : \(VT^3 = \) cste ; détente libre : \(VT^4 = \) cste ; \(N/V = 2{,}03\times10^{7}\,T^3\) m⁻³ ; \(\bar\varepsilon_{photon} = 2{,}70\,kT\) \(p = u/3\) pour un gaz relativiste ; l'expansion de l'Univers refroidit le fond cosmologique comme \(1/R\)

Cours 9 - Propriétés électriques de la matière

Niveau de Fermi \(\displaystyle \bar n(\varepsilon) = \frac{1}{e^{\beta(\varepsilon - \mu)} + 1}\) ; \(\bar n(\mu) = \tfrac{1}{2}\) \(\mu\) : niveau de Fermi ; métal si \(\mu\) est dans une bande, semiconducteur ou isolant s'il est dans la bande interdite \(\varepsilon_{gap} = \varepsilon_c - \varepsilon_v\)
Occupation au bord des bandes \(\bar n_e \approx e^{-\beta(\varepsilon - \mu)}\) pour \(\varepsilon \ge \varepsilon_c\) ; \(\bar n_h = 1 - \bar n_e \approx e^{\beta(\varepsilon - \mu)}\) pour \(\varepsilon \le \varepsilon_v\) si \(\mu\) est à plusieurs \(kT\) des deux bandes (non dégénéré) ; \(kT = 0{,}0259\) eV à 300 K
Densité d'états de la bande de conduction \(\displaystyle g(\varepsilon) = \frac{4\pi(2m^*)^{3/2}}{h^3}\sqrt{\varepsilon - \varepsilon_c}\) par unité de volume, spin inclus ; \(m^*\) masse effective
Concentrations d'électrons et de trous

\(n_e = N_C\,e^{-\beta(\varepsilon_c - \mu)}\) ; \(n_h = N_V\,e^{\beta(\varepsilon_v - \mu)}\)

\(\displaystyle N_C = \frac{2(2\pi m_e^*kT)^{3/2}}{h^3}\) ; \(\displaystyle N_V = \frac{2(2\pi m_h^*kT)^{3/2}}{h^3}\)

 \(N_{C,V} = 2{,}51\times10^{25}\ \text{m}^{-3}\) \(\times\,(m^*T/300\,m)^{3/2}\) ; \(1\ \text{cm}^{-3} = 10^{6}\ \text{m}^{-3}\) ; Si réel : \(N_C = 2{,}86\times10^{19}\) cm⁻³
Loi d'action de masse \(n_e\,n_h = N_CN_V\,e^{-\beta(\varepsilon_c - \varepsilon_v)} = n_i^2\) ; \(n_i = \sqrt{N_CN_V}\,e^{-\varepsilon_{gap}/2kT}\) vraie avec ou sans dopage, à l'équilibre ; Si à 300 K : \(n_i = 1{,}5\times10^{10}\) cm⁻³ (mesuré), Ge \(2{,}5\times10^{13}\), GaAs \(2\times10^{6}\)
Niveau de Fermi intrinsèque \(\displaystyle \mu = \frac{\varepsilon_c + \varepsilon_v}{2} + \frac{kT}{2}\ln\frac{N_V}{N_C} = \frac{\varepsilon_c + \varepsilon_v}{2} + \frac{3kT}{4}\ln\frac{m_h^*}{m_e^*}\) pratiquement au milieu de la bande interdite
Dopage de type N \(n_e \approx N_D\) ; \(n_h = n_i^2/N_D\) ; \(\displaystyle \mu = \varepsilon_c - kT\ln\frac{N_C}{N_D}\) donneurs à 5 électrons de valence (As, P), niveau \(\varepsilon_d\) à 0,03 eV sous \(\varepsilon_c\) ; manuel : états donneurs \(\mathcal N_d = 2N_D\), donc \(\ln(2N_c/\mathcal N_d)\)
Dopage de type P \(n_h \approx N_A\) ; \(n_e = n_i^2/N_A\) ; \(\displaystyle \mu = \varepsilon_v + kT\ln\frac{N_V}{N_A}\) accepteurs à 3 électrons de valence (B), niveau \(\varepsilon_a\) à 0,05 eV au-dessus de \(\varepsilon_v\)
Régimes en température ionisation → extrinsèque (\(n \approx N_D\)) → intrinsèque (\(n \approx n_i\)) ; \(\displaystyle T_{intrinsèque} \approx \frac{\varepsilon_{gap}}{2k\ln(N_C/N_D)}\) transition quand \(n_i(T) = N_D\) ; \(N_C\) dépend de \(T\) (itérer)
Courant de dérive \(\vec J = \sigma\vec E\) ; \(\sigma = 1/\rho = e\,n\,\mu\) ; \(\sigma = e(n_e\mu_e + n_h\mu_h)\) ; \(v_d = \mu E\) \(\mu\) : mobilité en m²/(V s) ; Si : \(\mu_n = 1350\), \(\mu_p = 480\) cm²/(V s) ; métaux : \(\sigma \approx C/T\)
Modèle de Drude, résistance \(\displaystyle I = J_xA = e\,n\,A\,v_d = e\,n\,A\,\mu E_x\) ; \(\displaystyle R = \frac{V}{I} = \frac{L}{e\,n\,A\,\mu} = \frac{\rho L}{A}\) barreau de longueur \(L\) et de section \(A\)
Courant de diffusion (loi de Fick) \(\displaystyle \phi = -D\frac{dn}{dx}\), \(D = \bar\ell^{\,2}/2\tau\) ; \(\displaystyle J_{n,\,diff} = eD_n\frac{dn}{dx}\) ; \(\displaystyle J_{p,\,diff} = -eD_p\frac{dp}{dx}\) flux vers les faibles concentrations ; le courant des électrons est opposé à leur flux
Courants totaux \(\displaystyle J_n = e\,n\,\mu_nE + eD_n\frac{dn}{dx}\) ; \(\displaystyle J_p = e\,p\,\mu_pE - eD_p\frac{dp}{dx}\) dérive + diffusion ; les deux courants de dérive sont dans le sens de \(E\)
Relation d'Einstein \(\displaystyle \frac{D_n}{\mu_n} = \frac{D_p}{\mu_p} = \frac{kT}{e}\) 25,9 mV à 300 K ; Si : \(D_n = 35\), \(D_p = 12{,}5\) cm²/s
