Comment utiliser ce site

  1. Théorie : chaque module suit l'ordre du cours, avec le code des TP comme fil conducteur. Les encadrés « Question d'examen classique » signalent ce qui est tombé aux intras passés.
  2. Démos : exécutez le code pas à pas (constructions, destructions, pointeurs), devinez l'affichage avant de vérifier, manipulez les simulateurs (shared_ptr, vector, liaison dynamique, conversions, exceptions, algorithmes).
  3. Quiz : 12 à 15 questions par module ; le meilleur score est mémorisé dans ce navigateur. Lisez les explications, elles contiennent la justification attendue aux vrai/faux.
  4. Exercices : écrivez le code sur papier ou dans un éditeur avant de déplier la solution ; cochez « Fait ». Les énoncés marqués « Intra » viennent des séances de révision d'intras passés (A2018, H2019).
  5. Avant l'examen : les pages Intra et Final (stratégie, quiz de révision, synthèses chronométrées) et l'aide-mémoire à imprimer ou à mettre sur la clé USB avec le site.

Rappels du plan de cours

  • Contrôle périodique (1 h 50) et examen final : sur Moodle Examen, toute documentation sur papier ou sur clé USB ; questions de programmation C++ (analyse du problème, conception du programme, écriture de code). Vérifiez vous-même que vos fichiers s'ouvrent sur la clé.
  • TP en équipe de deux, de la même section ; remise sur Moodle, un seul membre soumet, les deux vérifient ; retard = 0. Compilation sans erreur ni avertissement (-std=c++20 -Wall -Wextra -pedantic-errors), liste d'initialisation obligatoire, définitions dans le .cpp dans l'ordre du .h.
  • Les systèmes d'IA générative sont interdits pour les TP, quiz, intra et final.
  • Centre de consultation du lundi au vendredi, 11h30 à 14h30, au M-4018.
