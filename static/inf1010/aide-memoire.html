Aide-mémoire C++ pour INF1010

Une section par module : la syntaxe exacte, les signatures à recopier, les règles à vérifier avant de rendre. Sections 1 à 7 : intra. Sections 8 à 10 : final.

1. Classes, constructeurs, allocation dynamique

Déclaration (.h) Jamais using namespace std; dans un .h. Définitions dans le .cpp dans le même ordre (sauf génériques : dans le .h).
Définition (.cpp) Liste d'initialisation obligatoire pour const, références, attributs objets sans constructeur par défaut, classe de base. Ordre réel = ordre de déclaration des attributs.
Constructeurs

Par défaut T(); (fourni seulement si aucun constructeur déclaré) ; par paramètres ; par copie T(const T&); (appelé par T b = a;, T b(a);, paramètre par valeur, retour par valeur, new T(a), push_back(a)).

explicit T(int n); interdit la conversion implicite T t = 5;.

Pas de type de retour. Un tableau T t[3] ou new T[3] exige le constructeur par défaut.
Ordre de construction / destruction

Construction : classe(s) de base (ordre de la déclaration de classe), attributs (ordre de déclaration), corps. Destruction : corps du destructeur, attributs (inverse), base.

Variables locales détruites à l'accolade fermante, ordre inverse de déclaration. Temporaire : fin de l'expression. Paramètre par valeur : fin de la fonction. Objet dynamique : au delete seulement.

À appliquer pour « Donnez l'affichage ».
Pile et tas Un new = un delete, un seul propriétaire. Erreurs : fuite, pointeur pendant, double delete, delete sur un tableau, delete sur une variable locale.
Agrandir un tableau Ce que vector fait tout seul.

2. const, passage de paramètres, vector

Méthode const

double get() const; : ne modifie pas *this, ne peut appeler que des méthodes const, ne retourne pas de T& vers un attribut. Seules les méthodes const sont appelables sur un objet const ou une const T&.

Le const fait partie de la signature : à répéter dans le .cpp. Surcharge possible : T& operator[](size_t) et const T& operator[](size_t) const.

Accesseurs, affichage, calculs, comparaisons : const.

4. this, opérateurs, copie et affectation

this

this : pointeur vers l'objet courant (const T* dans une méthode const). this->x en cas de conflit de noms ; return *this; pour le chaînage ; if (this != &autre) contre l'auto-affectation.

Signatures des opérateurs Membre : opérande gauche = objet. Libre/friend : opérande gauche d'un autre type ou commutativité. friend = fonction globale avec accès privé (pas de T::). Sans friend : passer par les accesseurs publics. a + b → a.operator+(b) ou operator+(a, b). Pas de nouveaux opérateurs, priorité inchangée.
Règle des trois Nécessaire si la classe possède un pointeur brut (new / delete) ou un unique_ptr. Inutile avec string, vector, shared_ptr, types simples (copie membre à membre correcte). Copie superficielle = partage involontaire, pointeur pendant, double delete.
Copie-et-échange (TP2) unique_ptr dupliqué (copie profonde), shared_ptr copiés (partage).

5. Héritage et polymorphisme

Syntaxe Héritage public = « est un ». Sans appel explicite, le constructeur par défaut de la base est utilisé. Seule la base directe dans la liste. Constructeurs, destructeurs, operator= non hérités.
Liaison

Non virtuelle : choisie à la compilation d'après le type déclaré du pointeur ou de la référence (liaison statique). Virtuelle : choisie à l'exécution d'après le type réel (liaison dynamique), uniquement via pointeur ou référence. Copie par valeur dans le type de base = découpage (slicing), version de la base.

Appel virtuel dans un constructeur/destructeur : version de la classe en cours. override : vérifie la redéfinition (signature et const identiques). final : interdit de redéfinir.

Collection polymorphe : vector<shared_ptr<Base>> ou unique_ptr ; jamais vector<Base>.
Abstraite / interface

Au moins une méthode = 0 → non instanciable (ni par valeur, ni en paramètre par valeur, ni dans vector<Base>). Une dérivée qui ne définit pas toutes les pures reste abstraite. Interface = que des pures + destructeur virtuel.

Erreur « impossible d'instancier une classe abstraite » : pure non redéfinie ou signature différente.

6. Conversions

AscendanteBase* p = &derivee; Base& r = derivee; shared_ptr<Base> s = make_shared<Derivee>(); : implicite, toujours valide. Base b = derivee; : valide mais découpe.
Descendante Jamais implicite. Préférer une méthode virtuelle à une chaîne de dynamic_cast. Usage légitime : opération propre à une dérivée (recharger une Batterie).

7. Héritage multiple et généricité

Héritage multiple Cas sain : une classe concrète + des interfaces.
Fonction générique Définition dans le .h. Erreurs à l'instanciation (T sans l'opérateur requis). Appel : filtrerParType<Pince>(liste).
Classe générique Tout dans le .h. Dans la classe, Liste = Liste<T>. shared_ptr : == compare les adresses.

10. Membres statiques, exceptions, Python (final)

static Variable de classe partagée par tous les objets ; existe même sans objet. static const int N = 3; initialisable dans la classe. Fonction libre static : visible dans son fichier seulement. Variable locale static : conserve sa valeur entre les appels.
Exceptions Le reste du bloc try est abandonné ; catch essayés dans l'ordre ; les objets locaux sont détruits (pointeurs intelligents libérés, pointeurs bruts fuient). Non attrapée : std::terminate. Hiérarchie : exception → logic_error (invalid_argument, out_of_range, length_error) et runtime_error (overflow_error, range_error) ; bad_alloc, bad_cast. noexcept : ne lance pas. Un destructeur ne lance jamais.
